# 验收清单

- [ ] A1 发问后切换到其他页面再切回，聊天历史完整保留

- [ ] A4 历史下拉切换会话正常，删除会话后列表与当前会话正确回落
- [ ] A5 后端 `conversations.db` 中消息与引用已落库；删除会话后消息级联清除
- [ ] A6 带无效 conversation_id 请求时静默回落新会话，界面不出错误弹窗
- [ ] A7 流式生成中点击停止，已生成部分仍被保存
- [ ] A8 前端 `npm run build` 通过；后端重启后历史仍在（持久化而非内存）
